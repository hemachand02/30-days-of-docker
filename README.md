# 30 Days of Docker

### A Practical Engineering Learning Journey

A structured, hands-on journey into Docker, containerization, Linux internals, and real-world application deployment.

## About This Repository

This repository documents my 30-day focused learning journey into Docker and containerization.

The objective is to develop a strong understanding of containerization technologies, explore the underlying Linux mechanisms, perform practical experiments, and apply the concepts through real-world implementation.

Rather than focusing exclusively on Docker commands, this journey emphasizes understanding how containers work internally, why particular technologies are used, and how they are applied in modern software development and deployment workflows.

## Learning Objectives

- Understand containerization and modern application deployment.
- Explore Docker architecture and its core components.
- Understand Linux namespaces, cgroups, and container isolation.
- Work with Docker images, containers, and storage.
- Understand container networking and inter-container communication.
- Build and optimize custom Docker images using Dockerfiles.
- Work with Docker Compose for multi-container applications.
- Explore container security, monitoring, and troubleshooting.
- Apply Docker to a practical Java application.

## Daily Learning Approach

Each day follows a practical engineering workflow:

1. Define the learning objectives.
2. Understand the underlying concepts.
3. Study the internal mechanisms and terminology.
4. Perform hands-on experiments.
5. Record observations and troubleshooting experiences.
6. Document the findings in Markdown.
7. Review and commit the changes using Git.

## Practical Implementation

The final phase will involve building a containerized Java application with MySQL, using Docker and Docker Compose.

The implementation will demonstrate how application services, databases, networking, storage, and configuration work together in a containerized environment.
